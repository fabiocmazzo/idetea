# IDE TEA: 機能とショートカット

[English](features.md) · [Français](features.fr.md) · [Deutsch](features.de.md) · [Italiano](features.it.md) · **日本語** · [中文（简体）](features.zh-CN.md)

技術的な読者向けの一覧です。短い版は [README](../README.ja.md) を参照してください。

> 1.0 より前です。Linux、macOS (Apple Silicon)、Windows (x86_64) でビルドとテストをしています。

## エディター

- 名前であいまい検索してファイルを開きます (`Ctrl+P`)。`main.rs:42` はその行へ直接移動します。
- ファイル内のシンボル (関数、型、メソッドなど) へ移動します (`Ctrl+Shift+O`)。プロジェクト内は `Ctrl+T` です。
- 変更マーク付きのタブ。開く (`Ctrl+O`)、保存、名前を付けて保存。システムのファイル ダイアログを使います。
- 約 200 の言語とファイルの種類の構文強調 (TOML、`.env`、INI、Dockerfile、TypeScript、Zig、
  [Ziex](https://ziex.dev) の `.zx` など)。ライトとダークのテーマ (iced のテーマ: Nord、Dracula など)。言語を増やすには、
  `.sublime-syntax` を `~/.config/idetea/syntaxes/` に置きます (IDE を開くときに読みます)。
- 検索と置換、行へ移動、元に戻す / やり直す、マルチ カーソル、コードの折りたたみ、任意の vim モード。
- エディターの一時ズーム (`Ctrl+=` / `Ctrl++`、`Ctrl+-`、`Ctrl+0`、または `Ctrl+ホイール`)。開いているタブと分割で共有します。
  ターミナルと、設定した基本サイズは変わりません。
- エディターの横の Markdown と SVG のプレビュー (`Ctrl+Shift+V`、またはタブ バーのボタン)。入力に合わせて更新します。
- 画像 (png、jpg、gif、webp、bmp、ico など) はタブで開きます。マウス ホイールのズームとドラッグがあります。
- PDF はタブで開きます (`hayro` による描画。純粋な Rust)。ズームと、幅に合わせるがあります。
- CRLF を保持します。UTF-8 でないファイルは、壊す代わりに開きません (警告付き)。
- 大きなファイル: 50 MB のファイルは 0.1 秒未満で開きます。1 行が巨大なファイル (ミニファイした JSON や JS) は、
  色なし、折り返しありの軽量モードで開くので、ウィンドウは固まりません。
- 保存時の任意の処理: 行末の空白を削る、末尾の改行、言語サーバーでのフォーマット。プロジェクトの `.editorconfig`
  が優先します。

## プロジェクト

- **ファイル ツリー:** 作成、名前の変更、削除 (ゴミ箱へ)、現在のファイルを表示、git の色 (変更、新規、
  競合、無視)。
- **プロジェクト検索。** 入力に合わせて、`.gitignore` を尊重します。正規表現、単語単位、大文字と小文字の区別があります。
- **右クリック メニュー。** ツリー、タブ、git パネルのファイル。
- **タスク** (`Ctrl+Shift+B`): 設定の自分のコマンドに加え、IDE がプロジェクトから見つけるもの (cargo、
  `package.json` のスクリプト、Makefile のターゲット、`build.zig` のステップ)。出力はターミナルです。MoonBit のモジュールには
  `moon check`、`build`、`test`、`fmt --check` もあります。アクティブなファイルに最も近い `moon.mod` から実行します。
- **新しいプロジェクト** (「プロジェクト: 新規…」、または `idetea new <folder>`): フォルダー、git、テンプレートのエージェント スキル (空、
  Rust、Web サイト、Python、FastAPI)、`AGENTS.md` の最初の依頼。[skills.ja.md](skills.ja.md) を参照してください。

## 言語 (LSP)

- エラーと警告 (エディターの波線と、診断のホバー、問題パネル、ステータス バーの件数)、補完、定義へ移動、フォーマット。
- 実装へ移動 (`Ctrl+F12`) と、型へ移動。結果が複数のときは、一覧がパネルへ行きます。
- 参照の検索 (`Shift+F12`、または宣言での `Ctrl+クリック`)。ファイルごとにグループ化します。各ジャンプのあと、戻る / 進む
  (`Alt+←` / `Alt+→`、またはマウスのサイド ボタン)。
- 呼び出し階層 (`Alt+Shift+H`): 関数を呼ぶものと、関数が呼ぶもの。開くと読み込むツリーです。
- アウトライン パネル (`Alt+7`): ファイルの関数、構造体、メソッド、フィールド。公開、非公開、
  制限 (`pub(crate)`、`protected` など) を示し、カーソル下のシンボルを強調します。
- エディター上のパンくずリスト: `project › folder › file › impl App › fn update`。カーソルがあるパスとシンボルです。
  フォルダーはツリーでファイルを表示し、シンボルはその場所へ移動します。`[editor] breadcrumbs = false` でオフです。
- コードのフォント: JetBrains Mono が内蔵です。インストール済みのフォントも使えます (`[editor] font = "Fira Code"`)。合字もです。
  太さと行の高さも (`font_weight`、`line_height`)。設定 → 外観でも変えられます。エディター、
  行番号、ターミナルは同じフォントです。
- 言語と種類ごとのファイル アイコン (VS Code の Seti セット。内蔵。Hare と
  MoonBit は IDE 独自のアイコン)。ファイル ツリー、タブ、Ctrl+P、パンくずリスト、
  検索結果、git パネルに出ます。`[ui] file_icons = "none"` (または設定 → 外観) で、すべてのファイルが 1 つのアイコンに戻ります。
- Shift+クリックは、最後のクリックから選択を伸ばします (キーボードでカーソルを動かしたあとは、カーソルから)。
- 単語単位: `Ctrl+Left/Right` は移動 (`Shift` で選択)、`Ctrl+Backspace/Delete` は削除。`Home` は行の
  最初の文字へ、次に列 0 へ。`Shift+Tab` はインデントを外します。
- 以前と違っていた VS Code のキー: カーソル位置のブロックの折りたたみ / 展開は `Ctrl+Shift+[` / `]`、
  最後に閉じたタブを開き直すのは `Ctrl+Shift+T`、下部パネルは `Ctrl+J`、ターミナルは `` Ctrl+` `` または `Ctrl+'`。
- 設定済み: rust-analyzer、clangd、pyright、typescript-language-server、gopls、lua-language-server、zls (Zig)、
  `zx lsp` ([Ziex](https://ziex.dev)。`zx` CLI がないとき、Ziex のプロジェクトは `zig build` で自分のサーバーをビルドします)、
  `hare-lsp -S`、`moon lsp`。サーバーをインストールするだけです。コマンドの変更、無効化、追加は
  設定でできます。Hare のサーバーは、解析の診断、定義、ホバー、ドキュメント シンボルに限られます。MoonBit の対応は
  `.mbt`、`.mbti`、`.mbt.md` (MoonBit のブロックを含む Markdown) で、インストールしたツールチェーンの能力に従います。言語ごとの詳細:
  [languages.ja.md](languages.ja.md)。

## ターミナル

- 下部パネルの統合ターミナル (alacritty)。テーマの色とフォントです。
- タブに複数のシェル (「ターミナル 1」「ターミナル 2」など)。タスク専用のタブもあります。`+` で開き、`×` で閉じ、
  `exit` でタブを閉じます。
- シェルのショートカット (`Ctrl+C`、`Ctrl+W` など) はシェルへ行きます。IDE の `Ctrl+Shift` ショートカットは動いたままです。

## Git

- ステータス バーに、ブランチ、先行 / 遅れのコミット、変更の件数。
- パネルで、ファイル単位またはすべてのステージ / ステージの解除、色付き差分、コミット、変更の破棄 (確認付き)。
- プッシュ、プル、フェッチ。IDE はパスワードを待ちません。ssh エージェントか、git の資格情報ヘルパーを使います。
- インストール済みの `git` を使うので、設定、フック、資格情報が適用されます。

## デバッグ

- 行番号のクリックでブレークポイント (`F9`)。編集するとテキストに追従します。
- `F5` はビルドして実行します。Rust のプロジェクトでは `cargo build` を使い、実行ファイルを見つけます。Zig のプロジェクトでは
  `zig build` と、`zig-out/bin` の実行ファイルです。MoonBit のモジュールでは `moon build --target native -g`
  (実験的。[languages.ja.md](languages.ja.md#moonbit) を参照)。それ以外は、設定の `[debug]`
  セクションが、プログラム、引数、ビルド コマンドを示します。
- ステップ オーバー、ステップ イン、ステップ アウト (`F10`、`F11`、`Shift+F11`)、一時停止、停止。現在の行をエディターに印します。
- パネルに、呼び出しスタック (クリックでフレームへ)、ツリーの変数、プログラムの出力。
- `gdb` 14 以降を使います (Rust、C、C++、Zig、および実験的に MoonBit)。

## エージェントとの作業

すべては、プロジェクトの `.idetea/` フォルダーのプレーンなファイルです。ファイルを読み書きできるエージェントなら使えます。
「インターフェース: このプロジェクトのエージェントに教える」は、手順を `AGENTS.md` と `CLAUDE.md` に書きます。

- **インターフェース** (`.idetea/ui/<name>.json`): エージェントがドキュメントを書くと、IDE はフォームとして表示します (テキスト、
  Markdown、選択、チェックボックス、入力、ボタン、手動テストの手順、編集するファイル、画像、ギャラリー、アニメーションする
  スプライト、波形とピーク レベル付きの音声)。回答は `.idetea/ui/responses/` に書きます。パネルは、
  エージェントがまだ待っているかを示します。形式: [docs/interfaces/formato.md](interfaces/formato.md)（現時点ではポルトガル語）。
- **エージェント ターミナル** (`.idetea/agents/<name>.json`): エージェントがコマンド付きのターミナルを要求します。IDE は
  「ターミナル要求」タブに要求の全文を出し、許可したあとだけ実行します。進行は
  `<name>.status.json` です (`pending`、`running`、コード付きの `exited`、`refused`、`closed`、`invalid`、`lost`)。
  要求を削除するとターミナルは止まります (コマンドが既に終わっていれば、タブは閉じるまで残ります)。
- **許可リスト:** 利用者の設定の `[agents] allow = ["npm run dev", "claude *"]` は、確認なしでそれらのコマンドを実行します。
  正確なコマンド、またはプレーンな引数だけが続く接頭辞です (`;`、`&`、`|`、`$`、バッククォート、
  リダイレクトなどは不可)。プロジェクトの設定では無視し、警告を出します。
- **専用 worktree のヘルパー:** `"worktree": "<branch>"` は、そのブランチの `.idetea/worktrees/<name>` でコマンドを実行します。
  すべてのコマンドは `IDETEA_ANSWER` を受け取ります。メイン プロジェクトにある、回答用のファイルです。要求を削除すると、
  未コミットのものがなければ worktree を削除します。ブランチは常に残ります。
- **エージェント向けコマンド:** `idetea ask` (パネルの質問。回答を待つ)、`idetea run` (ターミナル。
  終了とヘルパーの回答を待つ)、`idetea status` (開いているもの、未保存の変更、カーソル)、
  `idetea open file:line` (ファイルを表示)、`idetea history` (パネルで答えた内容)、`idetea mascot`
  (マスコットの状態と吹き出しをリアルタイムで)。上のファイル作業を 1 回の呼び出しで行い、承認は同じです。
- **反応するマスコット (Tea):** 右下のピクセル アートのティーカップ カード (ステータス バーへ折りたためる。
  コマンド パレットでも切り替え)。`.idetea/` をリアルタイムで見ます (`idle`、`working`、`thinking`、`attention`、
  `celebrating`、`error`、`sleeping`。ホバー、ダブルクリック、つつくと、対話の `curious` と `annoyed`)。
  状況ごとに短い台詞がいくつかあり、同じ台詞を連続では出しません。ファイルの
  保存、デバッグのビルドの成功と失敗、長い待機 (うとうとし、戻ると起きます)、時刻にも気づきます。夜遅いときは、休むようそっと示します。
  吹き出しのクリックは、インターフェース、ターミナル、問題のパネルを開き、フォーカスは奪いません。`[mascot] tips = true` (`chatty` が `quiet` でないとき) では、
  実在するショートカットを時々示します。`[mascot] chatty` は `quiet`、`normal`、`chatty` です。エージェントやフックは
  `idetea mascot <state> [--text "…"] [--source <name>] [--ttl <secs>]` で直接動かせます。カスタムのスプライト パックは
  `.idetea/mascot/mascot.toml` または `~/.config/idetea/mascots/<pack>/mascot.toml` です (`[mascot] enabled = true`)。
- **テキストの選択とコピー:** インターフェースの上部の「テキストを選択」(開いているもの、または履歴) は、テキストを
  読み取り専用のエディターに出します。マウスで選択し、Ctrl+C でコピーします。「整形して表示」で戻ります。
- **質問の履歴:** IDE は、すべての質問、回答、コメント、エージェントが読んだ時刻を
  `.idetea/history/` に残します (git の外。消去するまで)。左の **インターフェースの履歴** パネル (既定では非表示) は、
  開いている質問を先に、答えたものを日ごとに並べ、検索できます。項目は、答えたとおりに読み取り専用で開きます。
- **このプロジェクトを直す** (「インターフェース: このプロジェクトを直す」): クラッシュや
  悪い編集のあと、`.idetea/` を使える状態に戻します。**スキル:** `idetea skills` は、git リポジトリのエージェント スキルをプロジェクトへインストールします
  ([skills.ja.md](skills.ja.md))。

詳細: [terminais-de-agente.md](terminais-de-agente.md)（現時点ではポルトガル語）、[skills.ja.md](skills.ja.md)。

## インターフェース

- すべてのコマンドとショートカットがあるコマンド パレット (`Ctrl+Shift+P`)。
- ヘルプ (`F1`)。現在のすべてのショートカットと、短いガイド。
- 設定 (`Ctrl+,`): 外観、拡張機能、ショートカット (押したキーを記録)、言語サーバー。
- アクティビティ バーでパネルの表示と非表示。パネルはマウスでサイズを変えます。
- ファイルが開いていないときのウェルカム画面: 新しいファイル、ファイルまたはフォルダーを開く、最近のファイルとプロジェクト、主な
  ショートカット。入力か `Ctrl+N` で、無題のエディターに戻ります。
- パネルは、より暗い背景の上の角丸の島です。マウスが離れると薄くなる、細いピル型のスクロール バーです。
  `[ui] style = "classic"` は、線で区切った 1 つの背景に戻します。パレット、メニュー、ダイアログはそっと滑り込みます。
  `[ui] animations = false` でオフです。
- インターフェースは、ポルトガル語、英語、スペイン語、フランス語、ドイツ語、イタリア語、日本語、簡体字中国語です
  (`[ui] language`、またはシステム)。IDE を再起動すると反映されます。

## 作業を失わない

- 未保存の変更があるタブを閉じるとき、または終了するときは、必ず先に確認します。
- ファイルの削除は、システムのゴミ箱へ送ります。
- IDE の外で変わったファイル (ターミナル、`cargo fmt`、別のエディター、`git checkout`) には気づきます。ツリーと
  git は更新し、変更のないタブは再読み込みし、変更のあるタブは警告付きで残します。

## 主なショートカット

| ショートカット | 内容 |
|---|---|
| `Ctrl+P` | 名前でファイルを開く |
| `Ctrl+Shift+P` | コマンド パレット |
| `F1` | ヘルプ: すべてのショートカットとガイド |
| `Ctrl+,` | 設定 |
| `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | 開く / 保存 / 名前を付けて保存 |
| `Ctrl+B` | ファイル ツリーの表示 / 非表示 |
| `Ctrl+Shift+F` | プロジェクト内を検索 |
| `` Ctrl+` `` / `Ctrl+'` | ターミナル |
| `Ctrl+Shift+T` | 最後に閉じたタブを開き直す |
| `Ctrl+Shift+G` | Git |
| `Ctrl+Shift+M` / `F8` | 問題 / 次の問題 |
| `F12` | 定義へ移動 |

すべて、設定または `~/.config/idetea/config.toml` で変更できます。

## ソースからビルド

```sh
git clone https://github.com/fabiocmazzo/idetea && cd idetea
cargo build --release      # 実行ファイルは target/release/idetea
```

[`just`](https://github.com/casey/just) があると、`just run` はデスクトップ パネル用のアイコンもインストールします。
ターミナルでは、`idetea .` が IDE を開き、プロンプトを返します。`idetea -f .` は接続したままです (ログ付き)。
