# Glossaire français (IDE TEA)

Vouvoiement. Espace ordinaire avant `:` `;` `!` `?`. Un titre cité dans la prose reprend le `cmd-*` (« Fichier : enregistrer », pas « Sauver »). Les accords par défaut (`Ctrl+Shift+P`, `Shift+F12`, `Ctrl+Click`) restent tels quels. Entrée pour Enter, Échap pour Esc ; Maj seulement si Shift est le nom de la touche dans une phrase.
