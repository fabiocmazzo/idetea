# IDE TEA 简体中文术语表

界面文案按大陆开发者的习惯来写，对照 Visual Studio Code 与 JetBrains 的简体中文。中文和拉丁字母、数字之间不加空格（`打开main.rs，第42行`）。命令标题用半角冒号，形如「文件: 保存」。

编程用的 agent 译为**智能体**，不用**代理**。代理和 proxy、ssh 代理撞在一起；JetBrains Junie、通义灵码、TRAE 也都把这类编程助手叫智能体。已经译好的吉祥物句子原样保留，其中仍有「代理」二字，新文案不再这么用。

面板产品名 Interfaces 译为**界面**。命令前缀仍是「界面: …」，例如「界面: 显示面板」。

产品名、工具名、协议、命令行程序 `idetea`、标志（`--force`、`--apply`）、配置表与配置键、命令 id、路径，以及 Ctrl、Shift、Alt、Enter、Esc、F5 这类按键，保持拉丁字母。散文里的工作树写「工作树」；只有 `--worktree` 这种命令行记号才留 worktree。
