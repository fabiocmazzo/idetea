Nur der Code.
Eis darfst du selbst zugeben.

Eine schnelle, stille IDE, in der Coding-Agenten fragen, bevor sie handeln. Sie bleiben im Editor. Der Agent bleibt im Terminal. Die Frage erscheint als Formular, und nichts läuft, bis Sie es sagen.

Herunterladen Demo ansehen Stern auf GitHub

Linux (x86_64 und aarch64), macOS (Apple Silicon) und Windows (x86_64). Vor 1.0.

Für wen sie ist. Für Menschen, die neben Claude Code, Codex oder jedem Agenten programmieren, der AGENTS.md und CLAUDE.md liest, und die wollen, dass der Editor schnell öffnet, vorhersehbar bleibt und das Netz in Ruhe lässt.

Was Sie bekommen

Schnell

Öffnet und geht aus dem Weg

Startet deutlich unter 200 ms. Eine Datei von 50 MB öffnet in einer Zehntelsekunde. Eine minifizierte Datei mit einer riesigen Zeile öffnet in einem Leichtmodus, statt das Fenster einzufrieren.

Still

Kein Konto, keine Telemetrie, kein Marketplace

Keine Pop-ups über Funktionen, um die Sie nicht gebeten haben. Das Netz wird nur genutzt, wenn Sie es verlangen (Pushen, Pullen, Abrufen oder einen Skill, den Sie installieren). Die Einstellungen leben in einer schlichten TOML-Datei.

Am Steuer

Agenten fragen. Sie entscheiden.

Fragen sind echte Formulare: Auswahl, Kontrollkästchen, Schritte, Bilder, Klänge. Eine Terminalanfrage zeigt den ganzen Befehl. Ein Projekt kann sich nicht selbst auf Ihre Zulassungsliste setzen.

Editor

Vollständig, wo es zählt

Mehrfachcursor, optionaler Vim-Modus, Dateibaum, Projektsuche, LSP, git, ein integriertes Terminal, Debuggen mit gdb und Registerkarten für Markdown, SVG, Bilder und PDF.

Klein

Ein Kern, der nur Dateien bearbeitet

Baum, Terminal, git und der Debugger sind Erweiterungen, die Sie abschalten können. Tea, das Maskottchen in Pixel-Art, achtet auf eine wartende Frage und geht aus dem Weg, wenn Sie es einklappen.

Warum IDE TEA

Aus dem ehrlichen Vergleich mit VS Code, Cursor, Zed, JetBrains und Helix. Diese Notiz entstand um 0.4.0. Versionen seither liefern auch macOS (Apple Silicon) und Windows (x86_64).

Darum geht es

  • Terminal-Agenten bekommen ein dateibasiertes Protokoll: Formulare, genehmigte Befehle, Worktrees und das Maskottchen Tea. Der Verlauf jeder Antwort bleibt im Projekt.
  • Starte Claude Code, Codex oder Gemini CLI mit Ctrl+Shift+A, zeig mit Ctrl+L auf den Code und führe ein Projektgedächtnis in einfachen Dateien, das alle Agenten teilen.
  • Kein Konto und keine Telemetrie. Das Programm meldet sich nicht von selbst.
  • Schnelles Öffnen, und große oder minifizierte Dateien, die das Fenster nicht einfrieren.

Darum geht es nicht

  • Keine Ghost-Text-Vervollständigung. Das ist eine Entscheidung, kein fehlender Schalter.
  • Keine Inline-Diffs der Art „diesen Hunk annehmen“. Wenn ein Agent eine Datei bearbeitet, prüfen Sie sie im Git-Bereich.
  • Code Actions, Inlay Hints und die Abdeckung des Debuggers liegen hinter VS Code und JetBrains. Der Vergleich sagt das.

Installation

Startklar über das neueste Release. SHA256SUMS enthält die Prüfsummen.

Linux

x86_64 und aarch64, .tar.gz oder .AppImage. ./install.sh legt idetea nach ~/.local/bin und ins Anwendungsmenü. Das AppImage braucht chmod +x; --install-desktop fügt den Menüeintrag hinzu.

macOS

Apple Silicon, ein .tar.gz mit IDE TEA.app. idetea --install-desktop legt ~/Applications/IDE TEA.app an.

Windows

x86_64, der Installer -setup.exe oder ein portables .zip. Kostenlose Codesignatur von SignPath.io, Zertifikat der SignPath Foundation.

Aus dem Quellcode (braucht Rust stable):

cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app
idetea --install-desktop

Optional: git für den Git-Bereich, gdb 14+ (oder lldb-dap unter macOS) zum Debuggen und die Sprachserver, die Sie nutzen. rust-analyzer, clangd, pyright, typescript-language-server, gopls, lua-language-server, zls, zx lsp, hare-lsp (Hare) und moon lsp (MoonBit) sind schon eingerichtet.

Zum Namen

Es begann als Wortspiel mit Iced Tea, weil die IDE mit iced gebaut ist. Auf Portugiesisch ist TEA auch die Abkürzung für Autismus. IDE TEA wird von einem autistischen Entwickler gemacht, und das zeigt sich in dem, was sie schätzt: wenig Lärm, klarer Text, Dinge, die sich jedes Mal gleich verhalten, und Raum zum Konzentrieren.

Lesen Sie das Manifest. Die vollständige Funktionsliste steht auf der Seite der Funktionen.
