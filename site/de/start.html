1. Installation

  1. Laden Sie das Paket für Ihre Plattform herunter (.tar.gz oder .AppImage für Linux x86_64/aarch64, .tar.gz mit IDE TEA.app für macOS aarch64 oder den Installer -setup.exe / das portable .zip für Windows x86_64) vom neuesten Release. SHA256SUMS enthält die Prüfsummen.
  2. Unter Linux packen Sie es aus und führen den Installer aus. Er legt idetea nach ~/.local/bin und fügt IDE TEA Ihrem Anwendungsmenü hinzu: 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. Wenn der Installer sagt, dass ~/.local/bin nicht auf Ihrem PATH liegt, fügen Sie es hinzu (zum Beispiel in ~/.profile), damit Sie und Ihre Agenten idetea aus einem Terminal ausführen können.

Lieber eine einzelne Datei unter Linux? Das AppImage läuft, wie es ist: chmod +x IDE_TEA-*.AppImage und öffnen; --install-desktop fügt es dem Menü hinzu. Unter macOS legt idetea --install-desktop ~/Applications/IDE TEA.app an. Aus dem Quellcode bauen ist ein Befehl: cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

Die kostenlose Codesignatur unter Windows stellt SignPath.io, das Zertifikat die SignPath Foundation (Codesignatur und Datenschutz).

Optional dazu: git für den Git-Bereich, gdb 14+ (oder lldb-dap unter macOS) zum Debuggen und die Sprachserver, die Sie nutzen (die nächsten Schritte).

2. Ein Projekt öffnen

Ein Projekt ist nur ein Ordner. Aus einem Terminal:

idetea                # der aktuelle Ordner
idetea ~/code/meine-app  # ein anderer Ordner
idetea src/main.rs    # aktueller Ordner, mit dieser Datei offen

Die IDE gibt die Eingabeaufforderung sofort zurück. Aus dem Anwendungsmenü öffnet sie Ihr letztes Projekt wieder. Die Registerkarten, die aktive Datei und die offenen Bereiche kommen so zurück, wie Sie sie verlassen haben.

Das Layout: der Dateibaum links, der Editor in der Mitte, Bereiche rechts (Gliederung, Vorschau, Interfaces) und unten (Terminal, Suche, Probleme, Git). Über dem Editor zeigen die Brotkrümel den Pfad der Datei und das Symbol, an dem der Cursor steht. Die Symbolleiste am linken Rand zeigt und verbirgt jeden Bereich; ziehen Sie an einem Rand, um die Größe zu ändern.

3. Alles finden: drei Tastenkürzel

  1. Ctrl+P öffnet eine Datei nach Namen. Tippen Sie Teile des Namens; main.rs:42 springt zur Zeile.
  2. Ctrl+Shift+P ist die Befehlspalette: jeder Befehl, mit seinem Tastenkürzel daneben. Wenn Sie sich ein Tastenkürzel merken, dann dieses.
  3. F1 listet jedes Tastenkürzel, das Sie jetzt haben, dazu eine kurze Anleitung.

Durchsuchen Sie das ganze Projekt mit Ctrl+Shift+F (während Sie tippen, unter Beachtung von .gitignore, mit Regex und Ersetzen).

4. Sprachserver

Fehler, Vervollständigung, Hover, Gehe zu Definition (F12), Verweise (Shift+F12) und die Gliederung kommen von Sprachservern. Diese sind schon eingerichtet; installieren Sie die, die Sie brauchen, und sie starten von selbst:

SpracheServer

C, C++clangd
Pythonpyright

Zigzls
Ziexzx lsp
Harehare-lsp -S

Hare und MoonBit werden mit der IDE ausgeliefert (Syntax, Aufgaben und der voreingestellte Serverbefehl). Weitere lassen sich in der Konfiguration hinzufügen (Abschnitt [lsp]). Die Einzelheiten je Sprache stehen in languages.de.md.

5. Terminal und Aufgaben

  • Ctrl+' oder Ctrl+` fokussiert das Terminal. + öffnet eine weitere Shell in einer Registerkarte; exit schließt sie. Die Tastenkürzel der IDE mit Ctrl+Shift funktionieren weiter, während Sie darin tippen.
  • Ctrl+Shift+B führt eine Aufgabe aus: was die IDE im Projekt findet (cargo, Skripte aus package.json, Makefile-Ziele) plus Ihre eigenen, aus der Konfiguration: 
    # .idetea/config.toml im Projekt
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G öffnet den Git-Bereich: Stagen und das Staging aufheben, farbiger Diff, Commit, Änderungen verwerfen (mit Bestätigung), Pushen, Pullen und Abrufen. Er nutzt Ihr installiertes git, also gelten Ihre Konfiguration, Hooks, der ssh-Agent und der Credential-Helper. Der Branch und die Zahl der Änderungen stehen in der Statusleiste.

7. Einstellungen

Ctrl+, öffnet die Einstellungen: Darstellung, Erweiterungen, Tastenkürzel (drücken Sie die Tasten, die Sie wollen) und Sprachserver. Alles steht auch in schlichtem TOML:

  • ~/.config/idetea/config.toml für Sie;
  • .idetea/config.toml in einem Projekt, für dieses Projekt (sie hat Vorrang vor Ihrer).
[ui]
theme = "dark"          # "light", oder ein Design von iced wie "Nord" oder "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # eine installierte Schriftart, oder "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
