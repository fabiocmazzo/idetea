1. Instalar

  1. Descarga el paquete de tu sistema (.tar.gz o .AppImage para Linux x86_64/aarch64, .tar.gz con IDE TEA.app para macOS aarch64, o el instalador -setup.exe / .zip portátil para Windows x86_64) de la última versión. SHA256SUMS tiene las sumas de verificación.
  2. En Linux, descomprímelo y ejecuta el instalador. Pone idetea en ~/.local/bin e IDE TEA en el menú de aplicaciones: 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. Si el instalador avisa que ~/.local/bin no está en tu PATH, agrégalo (por ejemplo en ~/.profile), para que tú y tus agentes puedan ejecutar idetea desde una terminal.

¿Prefieres un solo archivo en Linux? El AppImage funciona tal cual: chmod +x IDE_TEA-*.AppImage y ábrelo; --install-desktop lo agrega al menú. En macOS, idetea --install-desktop crea ~/Applications/IDE TEA.app. Compilar desde el código es un comando: cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

La firma gratuita de código en Windows es de SignPath.io, certificado de la SignPath Foundation (política de firma y privacidad).

Extras opcionales: git para el panel de git, gdb 14+ (o lldb-dap en macOS) para depurar, y los servidores de lenguaje que uses (siguientes pasos).

2. Abrir un proyecto

Un proyecto es solo una carpeta. Desde una terminal:

idetea                # la carpeta actual
idetea ~/code/my-app  # otra carpeta
idetea src/main.rs    # la carpeta actual, con este archivo abierto

El IDE te devuelve el prompt enseguida. Desde el menú de aplicaciones, reabre tu último proyecto. Las pestañas, el archivo activo y los paneles abiertos vuelven como los dejaste.

La disposición: el árbol de archivos a la izquierda, el editor en el medio, paneles a la derecha (estructura, vista previa, Interfaces) y abajo (terminal, búsqueda, problemas, git). Encima del editor, los breadcrumbs muestran la ruta del archivo y el símbolo donde está el cursor. La barra de íconos del borde izquierdo muestra y oculta cada panel; arrastra un borde para cambiar su tamaño.

3. Encontrar cualquier cosa: tres atajos

  1. Ctrl+P abre un archivo por nombre. Escribe partes del nombre; main.rs:42 salta a la línea.
  2. Ctrl+Shift+P es la paleta de comandos: todos los comandos, con su atajo al lado. Si vas a recordar un solo atajo, que sea este.
  3. F1 lista todos los atajos que tienes ahora, más una guía corta.

Busca en todo el proyecto con Ctrl+Shift+F (mientras escribes, respetando el .gitignore, con regex y reemplazo).

4. Servidores de lenguaje

Errores, autocompletado, hover, ir a la definición (F12), referencias (Shift+F12) y la estructura vienen de los servidores de lenguaje. Estos ya vienen configurados; instala los que necesites y arrancan solos:

Se pueden agregar otros en la configuración (sección [lsp]).

5. Terminal y tareas

  • Ctrl+Shift+T abre la terminal. + agrega otro shell en una pestaña; exit la cierra. Los atajos Ctrl+Shift del IDE siguen funcionando mientras escribes en ella.
  • Ctrl+Shift+B ejecuta una tarea: lo que el IDE encuentra en el proyecto (cargo, scripts de package.json, objetivos del Makefile) más las tuyas, de la configuración: 
    # .idetea/config.toml en el proyecto
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G abre el panel de git: stage y unstage, diff con colores, commit, descartar (con confirmación), push, pull y fetch. Usa el git instalado, así que valen tu configuración, los hooks, el agente ssh y el credential helper. La rama y el número de cambios están en la barra de estado.

7. Configuración

Ctrl+, abre la pantalla de configuración: apariencia, extensiones, atajos (presiona las teclas que quieras) y servidores de lenguaje. Todo está también en TOML simple:

  • ~/.config/idetea/config.toml para ti;
  • .idetea/config.toml en un proyecto, solo para ese proyecto (gana sobre el tuyo).
[ui]
theme = "dark"          # "light", o un tema de iced como "Nord" o "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # cualquier fuente instalada, o "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
