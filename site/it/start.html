1. Installazione

  1. Scarica il pacchetto per la tua piattaforma (.tar.gz o .AppImage per Linux x86_64/aarch64, .tar.gz con IDE TEA.app per macOS aarch64, oppure l'installer -setup.exe / lo .zip portatile per Windows x86_64) dall'ultima release. SHA256SUMS ha le somme di controllo.
  2. Su Linux, scompattalo ed esegui l'installer. Mette idetea in ~/.local/bin e aggiunge IDE TEA al menu delle applicazioni: 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. Se l'installer dice che ~/.local/bin non è nel PATH, aggiungilo (per esempio in ~/.profile), così tu e i tuoi agenti potete eseguire idetea da un terminale.

Preferisci un file solo su Linux? L'AppImage parte così com'è: chmod +x IDE_TEA-*.AppImage e aprila; --install-desktop la aggiunge al menu. Su macOS, idetea --install-desktop crea ~/Applications/IDE TEA.app. Compilare dal codice sorgente è un comando: cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

La firma gratuita su Windows è fornita da SignPath.io, certificato della SignPath Foundation (firma del codice e privacy).

Extra facoltativi: git per il pannello git, gdb 14+ (o lldb-dap su macOS) per il debug, e i server di linguaggio che usi (i passi successivi).

2. Apri un progetto

Un progetto è solo una cartella. Da un terminale:

idetea                # la cartella attuale
idetea ~/code/my-app  # un'altra cartella
idetea src/main.rs    # cartella attuale, con questo file aperto

L'IDE restituisce subito il prompt. Dal menu delle applicazioni riapre l'ultimo progetto. Le schede, il file attivo e i pannelli aperti tornano come li hai lasciati.

La disposizione: l'albero dei file a sinistra, l'editor al centro, i pannelli a destra (struttura, anteprima, Interfacce) e in basso (terminale, ricerca, problemi, git). Sopra l'editor, i breadcrumb mostrano il percorso del file e il simbolo dov'è il cursore. La barra attività sul bordo sinistro mostra e nasconde ogni pannello; trascina un bordo per ridimensionarlo.

3. Trova qualsiasi cosa: tre scelte rapide

  1. Ctrl+P apre un file per nome. Scrivi pezzi del nome; main.rs:42 salta alla riga.
  2. Ctrl+Shift+P è il riquadro comandi: ogni comando, con la sua scelta rapida accanto. Se ne ricordi una sola, che sia questa.
  3. F1 elenca ogni scelta rapida che hai adesso, più una guida breve.

Cerca in tutto il progetto con Ctrl+Shift+F (mentre scrivi, nel rispetto di .gitignore, con regex e sostituzione).

4. Server di linguaggio

Errori, completamento, hover, vai alla definizione (F12), riferimenti (Shift+F12) e la struttura arrivano dai server di linguaggio. Questi sono già configurati; installa quelli che ti servono e partono da soli:

Hare e MoonBit arrivano con l'IDE (sintassi, attività e il comando predefinito del server). Gli altri si possono aggiungere nella config (sezione [lsp]). Il dettaglio per linguaggio è in languages.it.md.

5. Terminale e attività

  • Ctrl+' o Ctrl+` mette a fuoco il terminale. + aggiunge un'altra shell in una scheda; exit la chiude. Le scelte rapide Ctrl+Shift dell'IDE continuano a funzionare mentre ci scrivi.
  • Ctrl+Shift+B esegue un'attività: quello che l'IDE trova nel progetto (cargo, script di package.json, target del Makefile) più le tue, dalla config: 
    # .idetea/config.toml nel progetto
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G apre il pannello git: aggiungi a stage e rimuovi da stage, diff colorato, commit, ignora modifiche (con conferma), push, pull e recupera. Usa il git installato, quindi valgono la tua config, gli hook, lo ssh agent e il credential helper. Il ramo e il numero di modifiche sono sulla barra di stato.

7. Impostazioni

Ctrl+, apre la schermata delle impostazioni: aspetto, estensioni, scelte rapide (premi i tasti che vuoi) e server di linguaggio. Tutto sta anche in TOML in chiaro:

  • ~/.config/idetea/config.toml per te;
  • .idetea/config.toml in un progetto, per quel progetto (vince sulla tua).
[ui]
theme = "dark"          # "light", oppure un tema di iced come "Nord" o "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # un tipo di carattere installato, oppure "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
