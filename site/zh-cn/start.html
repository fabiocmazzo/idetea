1. 安装

  1. 下载你平台的包（Linux x86_64/aarch64用.tar.gz或.AppImage，macOS aarch64用带IDE TEA.app的.tar.gz，Windows x86_64用-setup.exe安装程序或便携.zip），从最新版本获取。SHA256SUMS里是校验和。
  2. 在Linux上，解压并运行安装脚本。它把idetea放到~/.local/bin，并把IDE TEA加进应用菜单： 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. 如果安装脚本说~/.local/bin不在PATH里，把它加进去（例如写在~/.profile），这样你和你的智能体都能从终端运行idetea。

在Linux上更想要单个文件？AppImage可以直接运行：chmod +x IDE_TEA-*.AppImage然后打开；--install-desktop会把它加进菜单。在macOS上，idetea --install-desktop会创建~/Applications/IDE TEA.app。从源码构建只要一条命令：cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app。

Windows上的免费代码签名由SignPath.io提供，证书来自SignPath Foundation（代码签名与隐私政策）。

可选的额外部分：git面板需要git，调试需要gdb 14+（macOS上可用lldb-dap），以及你要用的语言服务器（下一步）。

2. 打开项目

项目就是一个文件夹。从终端：

idetea                # 当前文件夹
idetea ~/code/my-app  # 另一个文件夹
idetea src/main.rs    # 当前文件夹，并打开这个文件

IDE会马上把提示符还给你。从应用菜单打开时，它会重新打开你上次的项目。选项卡、当前文件和打开的面板都会回到你离开时的样子。

布局：左边是文件树，中间是编辑器，右边是面板（大纲、预览、界面），底部是面板（终端、搜索、问题、git）。编辑器上方的痕迹显示文件路径和光标所在的符号。左边缘的图标栏用来显示和隐藏每个面板；拖动边界可以调整大小。

3. 找到任何东西：三条快捷键

  1. Ctrl+P按名称打开文件。输入名字的片段；main.rs:42会跳到那一行。
  2. Ctrl+Shift+P是命令面板：每一条命令，旁边写着它的快捷键。如果只记一条，就记这条。
  3. F1列出你现在的全部快捷键，外加一份简短指南。

用Ctrl+Shift+F搜索整个项目（随输入进行，遵守.gitignore，支持正则和替换）。

4. 语言服务器

错误、补全、悬停、转到定义（F12）、引用（Shift+F12）和大纲都来自语言服务器。下面这些已经配好；装上你需要的，它们会自己启动：

语言服务器
Rustrust-analyzer
C、C++clangd
Pythonpyright
TypeScript、JavaScripttypescript-language-server
Gogopls
Lualua-language-server
Zigzls
Ziexzx lsp
Harehare-lsp -S
MoonBitmoon lsp

Hare和MoonBit随IDE一起提供（语法、任务，以及默认的服务器命令）。其他语言可以在配置里添加（[lsp]段）。每种语言的细节在languages.zh-CN.md。

5. 终端和任务

  • Ctrl+'或Ctrl+`聚焦终端。+在选项卡里再开一个shell；exit关掉它。你在里面打字时，IDE的Ctrl+Shift快捷键仍然有效。
  • Ctrl+Shift+B运行任务：IDE在项目里找到的（cargo、package.json脚本、Makefile目标），再加上配置里你自己的： 
    # 项目里的.idetea/config.toml
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G打开git面板：暂存和取消暂存、带颜色的差异、提交、放弃更改（会确认）、推送、拉取和获取。它用你已经安装的git，所以你的配置、钩子、ssh agent和凭据助手都生效。分支和更改数量在状态栏上。

7. 设置

Ctrl+,打开设置：外观、扩展、快捷键（按下你想要的键）和语言服务器。这一切也都在普通的TOML里：

  • 给你自己的是~/.config/idetea/config.toml；
  • 给某个项目的是该项目里的.idetea/config.toml（它优先于你的）。
[ui]
theme = "dark"          # "light"，或iced的主题，例如"Nord"、"Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # 任何已安装的字体，或"monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
