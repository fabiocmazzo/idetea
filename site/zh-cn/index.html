快

打开，然后让开

启动远低于200ms。50MB的文件在零点一秒内打开。一行长到离谱的压缩文件会以轻量模式打开，而不是把窗口卡死。

没有你没要的功能弹窗。只有你要求时才用网络（推送、拉取、获取，或你安装的一项技能）。设置写在一个普通的TOML文件里。

为什么是IDE TEA

来自和VS Code、Cursor、Zed、JetBrains、Helix的诚实对比。那篇笔记写于0.4.0前后。此后的版本也提供macOS（Apple Silicon）和Windows x86_64。

要的就是这个

  • 终端里的智能体得到一套基于文件的协议：表单、经你批准的命令、工作树，以及吉祥物Tea。每一次回答的历史都留在项目里。
  • 没有账号，没有遥测。这个二进制不会自己往家里打电话。
  • 打开得快，大文件和压缩文件也不会把窗口卡死。

不是为了这个

  • 没有幽灵文本补全。这是取舍，不是藏起来的开关。
  • 没有行内“接受这一块”的差异。智能体改了文件，你在git面板里审。
  • 代码操作、内联提示和调试器的覆盖面，落后于VS Code和JetBrains。对比里就是这么写的。

安装

下载就能跑，从最新版本获取。SHA256SUMS里是校验和。

Linux

x86_64和aarch64，.tar.gz或.AppImage。./install.sh把idetea放到~/.local/bin，并加入应用菜单。AppImage需要chmod +x；--install-desktop会加入菜单项。

macOS

Apple Silicon，带IDE TEA.app的.tar.gz。idetea --install-desktop会创建~/Applications/IDE TEA.app。

Windows

x86_64，-setup.exe安装程序或便携.zip。免费代码签名由SignPath.io提供，证书来自SignPath Foundation。

从源码安装（需要稳定版Rust）：

cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app
idetea --install-desktop

可选：git面板需要git，调试需要gdb 14+（macOS上可用lldb-dap），以及你要用的语言服务器。rust-analyzer、clangd、pyright、typescript-language-server、gopls、lua-language-server、zls、zx lsp、hare-lsp（Hare）和moon lsp（MoonBit）已经配好。

关于这个名字

一开始是iced tea的双关，因为这个IDE用iced写成。在葡萄牙语里，TEA也是自闭症的缩写。IDE TEA由一名自闭症开发者写成，这体现在它看重的东西上：噪声低、文本清楚、每次行为都一样，并且留得出神的空间。
