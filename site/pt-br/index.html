Uma IDE rápida e silenciosa, em que os agentes de código perguntam antes de agir. Você fica no editor. O agente fica no terminal. A pergunta aparece como um formulário, e nada roda até você deixar.

Baixar Ver a demo Estrela no GitHub

Linux (x86_64 e aarch64), macOS (Apple Silicon) e Windows (x86_64). Antes da 1.0.

Para quem é. Para quem programa ao lado do Claude Code, do Codex ou de qualquer agente que leia o AGENTS.md e o CLAUDE.md, e quer um editor que abra rápido, seja previsível e não fique mexendo na rede.

O que você leva

Rápida

Abre e sai da frente

Começa bem abaixo de 200 ms. Um arquivo de 50 MB abre em um décimo de segundo. Um arquivo minificado, de uma linha só, abre num modo leve em vez de travar a janela.

Silenciosa

Sem conta, sem telemetria, sem marketplace

Nenhum pop-up de função que você não pediu. A rede só entra quando você pede (push, pull, fetch, ou uma skill que você instala). A configuração fica num arquivo TOML.

No comando

O agente pergunta. Você decide.

A pergunta é um formulário de verdade: escolhas, caixas, passos, imagens, sons. O pedido de terminal mostra o comando inteiro. Um projeto não consegue se colocar na sua lista de permissão.

Editor

Completa onde importa

Vários cursores, modo vim opcional, árvore de arquivos, busca no projeto, LSP, git, terminal integrado, depuração com gdb, e abas de Markdown, SVG, imagem e PDF.

Pequena

O núcleo só edita arquivo

Árvore, terminal, git e depurador são extensões que você pode desligar. O Tea, o mascote em pixel art, avisa quando tem pergunta esperando e some quando você recolhe.

Por que a IDE TEA

Do comparativo honesto com VS Code, Cursor, Zed, JetBrains e Helix. O texto é de por volta da 0.4.0. As versões de hoje também saem para macOS (Apple Silicon) e Windows (x86_64).

É disso que se trata

  • O agente do terminal ganha um protocolo feito de arquivos: formulários, comandos que você aprova, worktrees e o mascote Tea. O histórico de cada resposta fica no projeto.
  • Sem conta e sem telemetria. O binário não liga para casa.
  • Abre rápido, e arquivo grande ou minificado não trava a janela.

Não é disso que se trata

  • Não tem autocomplete fantasma enquanto você digita. É uma escolha, não um botão escondido.
  • Não tem diff “aceitar este pedaço” dentro do editor. Quando o agente edita um arquivo, a revisão é no painel do git.
  • Code actions, inlay hints e a cobertura do depurador ficam atrás do VS Code e do JetBrains. O comparativo diz isso.

Instalar

Pronta para rodar na versão mais recente. O SHA256SUMS tem as somas de verificação.

Linux

x86_64 e aarch64, .tar.gz ou .AppImage. O ./install.sh põe o idetea em ~/.local/bin e no menu. O AppImage precisa de chmod +x; --install-desktop cria a entrada do menu.

macOS

Apple Silicon, um .tar.gz com o IDE TEA.app. idetea --install-desktop cria ~/Applications/IDE TEA.app.

Windows

x86_64, o instalador -setup.exe ou um .zip portátil. Assinatura gratuita da SignPath.io, certificado da SignPath Foundation.

Pelo código (precisa do Rust estável):

cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app
idetea --install-desktop

Opcionais: git para o painel do git, gdb 14+ (ou lldb-dap no macOS) para depurar, e os servidores de linguagem que você usa. rust-analyzer, clangd, pyright, typescript-language-server, gopls, lua-language-server, zls, zx lsp, hare-lsp (Hare) e moon lsp (MoonBit) já vêm configurados.

Sobre o nome

Começou como trocadilho com iced tea, chá gelado, porque a IDE é feita com o iced. Em português, TEA também é a sigla de Transtorno do Espectro Autista. A IDE TEA é feita por um desenvolvedor autista, e isso aparece no que ela valoriza: pouco ruído, texto claro, coisa que se comporta sempre do mesmo jeito, e espaço para se concentrar.
