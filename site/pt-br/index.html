IDE TEA

Just code. Add ice.

Uma IDE rápida e silenciosa, em Rust puro, feita para trabalhar lado a lado com agentes de código. Os agentes perguntam antes de agir, e quem manda é você.

Baixar para Linux Primeiros passos Código no GitHub

Gratuita e de código aberto (Apache 2.0). Antes da 1.0: feita e testada no Linux; macOS e Windows ainda não.

Um editor que não atrapalha

Rápida

Abre bem abaixo de 200 ms. Um arquivo de 50 MB abre em um décimo de segundo; um arquivo minificado com uma linha gigante abre num modo leve em vez de travar a janela.

Silenciosa

Sem conta, sem telemetria, sem pop-ups. A rede só é usada quando você pede (push, pull, fetch). As configurações ficam num arquivo TOML simples.

Completa onde importa

LSP, git, terminal integrado, depuração com gdb, busca no projeto, abas de Markdown/SVG/PDF/imagem, vários cursores e um modo vim opcional.

Previsível

Todos os atalhos num lugar só (F1) e mudáveis. Fechar algo não salvo sempre pergunta. Apagar um arquivo manda para a lixeira.

Os agentes falam com você pela IDE

Muita gente hoje programa com um agente num terminal ao lado do editor. Em vez de uma caixa de chat pendurada no canto, a IDE TEA dá aos agentes um protocolo pequeno, feito de arquivos. Qualquer agente que lê o AGENTS.md ou o CLAUDE.md consegue usar: Claude Code, Codex e outros.

Perguntas como formulários de verdade

Escolhas, caixas de marcar, texto, passos de um teste manual, imagens e sons, no painel Interfaces. A sua resposta volta para o agente.

Terminais que você aprova

Um agente pode pedir um terminal. Você vê o comando inteiro antes, e nada roda até você permitir.

Ajudantes no próprio worktree

Passe uma revisão ou um conserto paralelo para outro agente. Ele trabalha no seu branch e deixa a resposta num arquivo.

Um comando para cada

idetea ask, run, status, open e history fazem o trabalho dos arquivos para o agente, com as mesmas aprovações.

Histórico de tudo

Cada pergunta e a sua resposta ficam guardadas, com quando o agente leu. Um painel mostra as abertas e as respondidas, com busca.

Instalar

Linux, pronta para rodar: baixe o .tar.gz ou o AppImage da sua máquina (x86_64 ou aarch64) na versão mais recente.

tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh      # põe o idetea em ~/.local/bin e no menu de aplicativos

Pelo código (precisa do Rust estável):

cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app
idetea --install-desktop   # opcional: entrada no menu e ícone

Sobre o nome

Começou como um trocadilho com iced tea (chá gelado), já que é feita com iced. Em português, TEA também é a sigla do Transtorno do Espectro Autista. A IDE TEA é feita por um desenvolvedor autista, e isso aparece no que ela valoriza: pouco ruído, texto claro, coisas que se comportam sempre do mesmo jeito e espaço para se concentrar.
