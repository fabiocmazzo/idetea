1. Instalar

A versão atual é a v0.20.0. O SHA256SUMS nessa página tem as somas de verificação. Troque o VERSION quando sair uma mais nova, ou pegue o arquivo na versão mais recente.

  1. Linux (x86_64). Descompacte e rode o instalador. Ele põe o idetea em ~/.local/bin e a IDE TEA no menu de aplicativos: 
    VERSION=0.20.0
curl -fsSL -O "https://github.com/fabiocmazzo/idetea/releases/download/v${VERSION}/idetea-${VERSION}-x86_64-linux.tar.gz"
tar -xzf idetea-${VERSION}-x86_64-linux.tar.gz
cd idetea-${VERSION}-x86_64-linux
./install.sh
    No ARM, use idetea-${VERSION}-aarch64-linux.tar.gz. Prefere um arquivo só? Baixe IDE_TEA-${VERSION}-x86_64.AppImage (ou IDE_TEA-${VERSION}-aarch64.AppImage), dê chmod +x e execute; --install-desktop põe no menu.
  2. macOS (Apple Silicon). O arquivo traz o IDE TEA.app: 
    VERSION=0.20.0
curl -fsSL -O "https://github.com/fabiocmazzo/idetea/releases/download/v${VERSION}/idetea-${VERSION}-aarch64-macos.tar.gz"
tar -xzf idetea-${VERSION}-aarch64-macos.tar.gz
cd idetea-${VERSION}-aarch64-macos
./idetea --install-desktop
    --install-desktop cria ~/Applications/IDE TEA.app. Ainda não há pacote para Mac com Intel.
  3. Windows (x86_64). Baixe e execute o IDE_TEA-0.20.0-x86_64-setup.exe, ou descompacte o idetea-0.20.0-x86_64-windows.zip portátil (o idetea.exe está dentro). No PowerShell: 
    $Version = "0.20.0"
Invoke-WebRequest -Uri "https://github.com/fabiocmazzo/idetea/releases/download/v$Version/IDE_TEA-$Version-x86_64-setup.exe" -OutFile "IDE_TEA-$Version-x86_64-setup.exe"
Start-Process ".\IDE_TEA-$Version-x86_64-setup.exe"
  4. Se o instalador do Linux disser que ~/.local/bin não está no PATH, adicione-o (por exemplo no ~/.profile), para você e os agentes rodarem o idetea no terminal.

Compilar pelo código-fonte é um comando (precisa do Rust estável). O pacote é tea-app; o binário se chama idetea: cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

O instalador do Windows ainda não tem assinatura de código, então o SmartScreen pode avisar na primeira execução (política de assinatura e privacidade).

Opcionais: git para o painel git, gdb 14+ (ou lldb-dap no macOS) para o debug, e os servidores de linguagem que você usa (próximos passos).

2. Abrir um projeto

Um projeto é só uma pasta. De um terminal:

idetea                # a pasta atual
idetea ~/code/my-app  # outra pasta
idetea src/main.rs    # a pasta atual, com este arquivo aberto

A IDE devolve o prompt na hora. Pelo menu de aplicativos, ela reabre o último projeto. As abas, o arquivo ativo e os painéis abertos voltam do jeito que você deixou.

O layout: a árvore de arquivos à esquerda, o editor no meio, painéis à direita (estrutura, prévia, Interfaces) e embaixo (terminal, busca, problemas, git). Acima do editor, os breadcrumbs mostram o caminho do arquivo e o símbolo onde está o cursor. A barra de ícones na borda esquerda mostra e esconde cada painel; arraste uma borda para mudar o tamanho.

3. Achar qualquer coisa: três atalhos

  1. Ctrl+P abre um arquivo pelo nome. Digite partes do nome; main.rs:42 vai direto à linha.
  2. Ctrl+Shift+P é a paleta de comandos: todos os comandos, com o atalho ao lado. Se for lembrar de um atalho só, que seja este.
  3. F1 lista todos os atalhos que você tem agora, mais um guia curto.

Busque no projeto inteiro com Ctrl+Shift+F (enquanto você digita, respeitando o .gitignore, com regex e substituição).

Erros, autocompletar, hover, ir para a definição (F12), referências (Shift+F12) e a estrutura vêm dos servidores de linguagem. Estes já vêm configurados; instale os que você precisa e eles começam sozinhos:

Hare e MoonBit vêm com a IDE (cores, tarefas e o comando padrão do servidor). Outros podem entrar na configuração (seção [lsp]). O detalhe por linguagem está em languages.md.

5. Terminal e tarefas

  • Ctrl+' ou Ctrl+` foca o terminal. + abre outro shell numa aba; exit fecha. Os atalhos Ctrl+Shift da IDE continuam valendo enquanto você digita nele.
  • Ctrl+Shift+B roda uma tarefa: o que a IDE acha no projeto (cargo, scripts do package.json, alvos do Makefile) mais as suas, da configuração: 
    # .idetea/config.toml no projeto
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G abre o painel do git: stage e unstage, diff colorido, commit, descartar (com confirmação), push, pull e fetch. Ele usa o git instalado, então a sua configuração, os hooks, o agente ssh e o credential helper valem. O branch e o número de mudanças ficam na barra de status.

7. Configurações

Ctrl+, abre a tela de configurações: aparência, extensões, atalhos (aperte as teclas que quer) e servidores de linguagem. Tudo também está em TOML simples:

  • ~/.config/idetea/config.toml para você;
  • .idetea/config.toml num projeto, só para ele (vale mais que o seu).
[ui]
theme = "dark"          # "light", ou um tema do iced como "Nord" ou "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # qualquer fonte instalada, ou "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
