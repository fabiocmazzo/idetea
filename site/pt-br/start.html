1. Instalar

  1. Baixe o .tar.gz da sua máquina (x86_64 ou aarch64) na versão mais recente. O SHA256SUMS tem as somas de verificação.
  2. Descompacte e rode o instalador. Ele põe o idetea em ~/.local/bin e a IDE TEA no menu de aplicativos: 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. Se o instalador avisar que ~/.local/bin não está no PATH, acrescente (por exemplo no ~/.profile), para você e os seus agentes rodarem o idetea de um terminal.

Prefere um arquivo só? O AppImage roda como está: chmod +x IDE_TEA-*.AppImage e abra; --install-desktop põe no menu. Compilar pelo código é um comando: cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

Extras opcionais: git para o painel do git, gdb 14+ para depurar, e os servidores de linguagem que você usa (próximos passos).

2. Abrir um projeto

Um projeto é só uma pasta. De um terminal:

idetea                # a pasta atual
idetea ~/code/my-app  # outra pasta
idetea src/main.rs    # a pasta atual, com este arquivo aberto

A IDE devolve o prompt na hora. Pelo menu de aplicativos, ela reabre o último projeto. As abas, o arquivo ativo e os painéis abertos voltam do jeito que você deixou.

O layout: a árvore de arquivos à esquerda, o editor no meio, painéis à direita (estrutura, prévia, Interfaces) e embaixo (terminal, busca, problemas, git). Acima do editor, os breadcrumbs mostram o caminho do arquivo e o símbolo onde está o cursor. A barra de ícones na borda esquerda mostra e esconde cada painel; arraste uma borda para mudar o tamanho.

3. Achar qualquer coisa: três atalhos

  1. Ctrl+P abre um arquivo pelo nome. Digite partes do nome; main.rs:42 vai direto à linha.
  2. Ctrl+Shift+P é a paleta de comandos: todos os comandos, com o atalho ao lado. Se for lembrar de um atalho só, que seja este.
  3. F1 lista todos os atalhos que você tem agora, mais um guia curto.

Busque no projeto inteiro com Ctrl+Shift+F (enquanto você digita, respeitando o .gitignore, com regex e substituição).

4. Servidores de linguagem

Erros, autocompletar, hover, ir para a definição (F12), referências (Shift+F12) e a estrutura vêm dos servidores de linguagem. Estes já vêm configurados; instale os que você precisa e eles começam sozinhos:

LinguagemServidor
Rustrust-analyzer
C, C++clangd
Pythonpyright
TypeScript, JavaScripttypescript-language-server
Gogopls
Lualua-language-server

Outros podem entrar na configuração (seção [lsp]).

5. Terminal e tarefas

  • Ctrl+Shift+T abre o terminal. + abre outro shell numa aba; exit fecha. Os atalhos Ctrl+Shift da IDE continuam valendo enquanto você digita nele.
  • Ctrl+Shift+B roda uma tarefa: o que a IDE acha no projeto (cargo, scripts do package.json, alvos do Makefile) mais as suas, da configuração: 
    # .idetea/config.toml no projeto
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G abre o painel do git: stage e unstage, diff colorido, commit, descartar (com confirmação), push, pull e fetch. Ele usa o git instalado, então a sua configuração, os hooks, o agente ssh e o credential helper valem. O branch e o número de mudanças ficam na barra de status.

7. Configurações

Ctrl+, abre a tela de configurações: aparência, extensões, atalhos (aperte as teclas que quer) e servidores de linguagem. Tudo também está em TOML simples:

  • ~/.config/idetea/config.toml para você;
  • .idetea/config.toml num projeto, só para ele (vale mais que o seu).
[ui]
theme = "dark"          # "light", ou um tema do iced como "Nord" ou "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true

[keys]
"ctrl+shift+p" = "palette.open"
