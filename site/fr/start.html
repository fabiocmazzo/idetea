1. Installation

  1. Téléchargez le paquet de votre plateforme (.tar.gz ou .AppImage pour Linux x86_64/aarch64, .tar.gz avec IDE TEA.app pour macOS aarch64, ou l'installateur -setup.exe / le .zip portable pour Windows x86_64) depuis la dernière version. SHA256SUMS contient les sommes de contrôle.
  2. Sous Linux, décompressez-le et lancez l'installateur. Il place idetea dans ~/.local/bin et ajoute IDE TEA au menu des applications : 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. Si l'installateur dit que ~/.local/bin n'est pas dans votre PATH, ajoutez-le (par exemple dans ~/.profile), pour que vous et vos agents puissiez lancer idetea depuis un terminal.

Vous préférez un seul fichier sous Linux ? L'AppImage s'exécute tel quel : chmod +x IDE_TEA-*.AppImage puis ouvrez-le ; --install-desktop l'ajoute au menu. Sous macOS, idetea --install-desktop crée ~/Applications/IDE TEA.app. Compiler depuis les sources tient en une commande : cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

La signature gratuite du code sous Windows est fournie par SignPath.io, certificat de la SignPath Foundation (politique de signature du code et de confidentialité).

En plus, si vous en avez besoin : git pour le panneau git, gdb 14+ (ou lldb-dap sous macOS) pour le débogage, et les serveurs de langage que vous utilisez (étapes suivantes).

2. Ouvrir un projet

Un projet, c'est simplement un dossier. Depuis un terminal :

idetea                # le dossier courant
idetea ~/code/my-app  # un autre dossier
idetea src/main.rs    # le dossier courant, avec ce fichier ouvert

L'IDE rend l'invite tout de suite. Depuis le menu des applications, il rouvre votre dernier projet. Les onglets, le fichier actif et les panneaux ouverts reviennent tels que vous les avez laissés.

La disposition : l'arborescence à gauche, l'éditeur au milieu, des panneaux à droite (plan, aperçu, Interfaces) et en bas (terminal, recherche, problèmes, git). Au-dessus de l'éditeur, le fil d'Ariane montre le chemin du fichier et le symbole où se trouve le curseur. La barre d'icônes sur le bord gauche affiche et masque chaque panneau ; faites glisser un bord pour le redimensionner.

3. Tout trouver : trois raccourcis

  1. Ctrl+P ouvre un fichier par son nom. Tapez des bouts du nom ; main.rs:42 saute à la ligne.
  2. Ctrl+Shift+P est la palette de commandes : chaque commande, avec son raccourci à côté. Si vous ne retenez qu'un raccourci, que ce soit celui-là.
  3. F1 liste tous les raccourcis que vous avez maintenant, plus un court guide.

Recherchez dans tout le projet avec Ctrl+Shift+F (au fil de la frappe, en respectant .gitignore, avec expression régulière et remplacement).

5. Terminal et tâches

  • Ctrl+' ou Ctrl+` donne le focus au terminal. + ajoute un autre shell dans un onglet ; exit le ferme. Les raccourcis Ctrl+Shift de l'IDE continuent de fonctionner pendant que vous tapez dedans.
  • Ctrl+Shift+B lance une tâche : ce que l'IDE trouve dans le projet (cargo, scripts de package.json, cibles de Makefile) plus les vôtres, depuis la configuration : 
    # .idetea/config.toml dans le projet
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G ouvre le panneau git : indexer et désindexer, diff coloré, valider, abandonner les modifications (avec confirmation), pousser, tirer et récupérer. Il utilise le git que vous avez installé, donc votre configuration, vos hooks, votre agent ssh et votre assistant d'identifiants s'appliquent. La branche et le nombre de modifications sont dans la barre d'état.

7. Paramètres

Ctrl+, ouvre l'écran des paramètres : apparence, extensions, raccourcis (pressez les touches que vous voulez) et serveurs de langage. Tout est aussi dans du TOML lisible :

  • ~/.config/idetea/config.toml pour vous ;
  • .idetea/config.toml dans un projet, pour ce projet (il l'emporte sur le vôtre).
[ui]
theme = "dark"          # "light", ou un thème d'iced comme "Nord" ou "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # n'importe quelle police installée, ou "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
