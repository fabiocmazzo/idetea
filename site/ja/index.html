高速で静かな IDE です。コーディング エージェントは、動く前に尋ねます。編集はエディター、エージェントはターミナルです。質問はフォームになり、承認するまで何も実行しません。

ダウンロード デモを見る GitHub でスター

Linux (x86_64 と aarch64)、macOS (Apple Silicon)、Windows (x86_64)。1.0 より前です。

対象。 Claude Code、Codex、または AGENTS.md と CLAUDE.md を読むエージェントのそばでコードを書き、エディターには速く開くこと、予測できること、ネットワークに手を出さないことを求める人向けです。

得られるもの

高速

開いて、邪魔をしない

起動は 200 ms を大きく下回ります。50 MB のファイルは 0.1 秒で開きます。1 行が巨大なミニファイ済みファイルは、ウィンドウを固める代わりに、軽量モードで開きます。

静か

アカウントなし、テレメトリなし、マーケットプレースなし

頼んでいない機能のポップアップはありません。ネットワークを使うのは、要求したときだけです (プッシュ、プル、フェッチ、またはインストールするスキル)。設定は 1 つのプレーンな TOML ファイルにあります。

承認

エージェントは尋ね、決定は残ります

質問は本物のフォームです。選択肢、チェックボックス、手順、画像、音声。ターミナルの要求はコマンド全文を表示します。プロジェクトが許可リストに自分を入れることはできません。

エディター

必要なところは一通り

マルチ カーソル、任意の vim モード、ファイル ツリー、プロジェクト検索、LSP、git、統合ターミナル、gdb によるデバッグ、Markdown、SVG、画像、PDF のタブです。

小さい中身

ファイルだけを編集するコア

ツリー、ターミナル、git、デバッグは、オフにできる拡張機能です。ピクセル アートのマスコット Tea は、待っている質問を見張り、折りたたむと退きます。

なぜ IDE TEA

率直な比較から。VS Code、Cursor、Zed、JetBrains、Helix との比較です。あの文書は 0.4.0 前後に書かれています。それ以降のリリースでは、macOS (Apple Silicon) と Windows (x86_64) も配布しています。

これが要点

  • ターミナルのエージェントは、ファイルベースの手順を得ます。フォーム、承認したコマンド、worktree、マスコット Tea です。すべての回答の履歴は、プロジェクトに残ります。
  • Ctrl+Shift+A で Claude Code、Codex、Gemini CLI を起動し、Ctrl+L でコードを指し、どのエージェントも共有するプロジェクトのメモリーをプレーン ファイルで残せます。
  • アカウントもテレメトリもありません。バイナリは、勝手に外部へ通信しません。
  • 速く開き、大きなファイルやミニファイ済みファイルでウィンドウは固まりません。

これが要点ではない

  • ゴースト テキストの補完はありません。足りないスイッチではなく、選択です。
  • インラインの「この hunk を採用」差分はありません。エージェントがファイルを編集したときは、git パネルで確認します。
  • コード アクション、インレイ ヒント、デバッグの対応範囲は、VS Code と JetBrains より後ろです。比較はそのように書いています。

インストール

すぐに実行できます。 最新リリースから。SHA256SUMS にチェックサムがあります。

Linux

x86_64 と aarch64。.tar.gz または .AppImage。./install.sh が idetea を ~/.local/bin とアプリ メニューに置きます。AppImage には chmod +x が必要です。--install-desktop がメニュー項目を追加します。

macOS

Apple Silicon。IDE TEA.app 入りの .tar.gz。idetea --install-desktop が ~/Applications/IDE TEA.app を作ります。

Windows

x86_64。-setup.exe インストーラー、またはポータブルな .zip。無料のコード署名は SignPath.io、証明書は SignPath Foundation です。

ソースから (Rust stable が必要):

cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app
idetea --install-desktop

任意: git パネル用の git、デバッグ用の gdb 14 以降 (macOS では lldb-dap)、使う言語サーバー。rust-analyzer、clangd、pyright、typescript-language-server、gopls、lua-language-server、zls、zx lsp、hare-lsp (Hare)、moon lsp (MoonBit) は設定済みです。

名前について

iced tea の洒落から始まりました。IDE は iced で作られているからです。ポルトガル語では、TEA は自閉スペクトラム症の略でもあります。IDE TEA は自閉スペクトラム症の開発者が作っていて、価値観に出ています。雑音が少ないこと、明確なテキスト、毎回同じように振る舞うこと、集中する余地です。

マニフェストを読んでください。機能の一覧は 機能のページ です。
