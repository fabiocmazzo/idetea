1. インストール

  1. プラットフォーム用のパッケージをダウンロードします (Linux x86_64/aarch64 は .tar.gz または .AppImage、 macOS aarch64 は IDE TEA.app 入りの .tar.gz、Windows x86_64 は -setup.exe インストーラーまたは ポータブルな .zip)。入手先は 最新リリースです。 SHA256SUMS にチェックサムがあります。
  2. Linux では、展開してインストーラーを実行します。idetea を ~/.local/bin に置き、IDE TEA を アプリ メニューに追加します。 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. インストーラーが、~/.local/bin は PATH にないと言うときは、追加します (例は ~/.profile)。ターミナルから idetea を実行でき、エージェントも実行できます。

Linux で 1 ファイルがよいときは、AppImage をそのまま実行します。chmod +x IDE_TEA-*.AppImage して開きます。 --install-desktop でメニューに追加します。macOS では、idetea --install-desktop が ~/Applications/IDE TEA.app を作ります。ソースからのビルドは 1 コマンドです。 cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app。

Windows の無料コード署名は SignPath.io が提供し、証明書は SignPath Foundation です (コード署名とプライバシーの方針)。

任意のもの: git パネル用の git、デバッグ用の gdb 14 以降 (macOS では lldb-dap)、 使う言語サーバー (次の手順)。

2. プロジェクトを開く

プロジェクトは、ただのフォルダーです。ターミナルから:

idetea                # 現在のフォルダー
idetea ~/code/my-app  # 別のフォルダー
idetea src/main.rs    # 現在のフォルダー。このファイルを開いた状態

IDE は、すぐにプロンプトを返します。アプリ メニューからは、最後のプロジェクトを開き直します。タブ、アクティブな ファイル、開いていたパネルは、離れたときの状態で戻ります。

配置: 左がファイル ツリー、中央がエディター、右がパネル (アウトライン、プレビュー、 インターフェース)、下がパネル (ターミナル、検索、問題、git) です。エディターの上のパンくずリストは、ファイルのパスと、 カーソルがあるシンボルを示します。左端のアイコン バーで 各パネルの表示と非表示を切り替えます。境界をドラッグしてサイズを変えます。

3. 何でも見つける: 3 つのショートカット

  1. Ctrl+P は、名前でファイルを開きます。名前の一部を入力します。main.rs:42 はその 行へ移動します。
  2. Ctrl+Shift+P はコマンド パレットです。すべてのコマンドと、その横のショートカットです。 1 つだけ覚えるなら、これです。
  3. F1 は、今のすべてのショートカットと、短いガイドを出します。

プロジェクト全体の検索は Ctrl+Shift+F です (入力に合わせて、.gitignore を尊重し、 正規表現と置換があります)。

4. 言語サーバー

エラー、補完、ホバー、定義へ移動 (F12)、参照 (Shift+F12)、 アウトラインは、言語サーバーから来ます。これらは設定済みです。必要なものをインストールすると、自分で起動します。

5. ターミナルとタスク

  • Ctrl+' または Ctrl+` でターミナルにフォーカスします。+ はタブにもう 1 つのシェルを追加し、 exit で閉じます。入力中も、IDE の Ctrl+Shift ショートカットは動いたままです。
  • Ctrl+Shift+B はタスクを実行します。IDE がプロジェクトから見つけるもの (cargo、 package.json のスクリプト、Makefile のターゲット) に加え、設定の自分のタスクです。 
    # プロジェクトの .idetea/config.toml
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G は git パネルを開きます。ステージとステージの解除、色付き差分、コミット、破棄 (確認付き)、プッシュ、プル、フェッチです。インストール済みの git を使うので、設定、フック、ssh エージェント、 資格情報ヘルパーが適用されます。ブランチと変更の件数は、ステータス バーにあります。

7. 設定

Ctrl+, は設定画面を開きます。外観、拡張機能、ショートカット (使いたいキーを押す)、 言語サーバーです。すべてはプレーンな TOML にもあります。

  • 利用者用は ~/.config/idetea/config.toml。
  • プロジェクト用は、そのプロジェクトの .idetea/config.toml (利用者の設定より優先します)。
[ui]
theme = "dark"          # "light"、または "Nord" や "Dracula" などの iced のテーマ
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # インストール済みのフォント、または "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
