Getting started

From download to a comfortable setup in about ten minutes.

1. Install

  1. Download the package for your platform (.tar.gz or .AppImage for Linux x86_64/aarch64, .tar.gz with IDE TEA.app for macOS aarch64, or the -setup.exe installer / portable .zip for Windows x86_64) from the latest release. SHA256SUMS has the checksums.
  2. On Linux, unpack it and run the installer. It puts idetea in ~/.local/bin and adds IDE TEA to your app menu: 
    tar -xzf idetea-*-linux.tar.gz
cd idetea-*-linux
./install.sh
  3. If the installer says ~/.local/bin is not on your PATH, add it (for example in ~/.profile), so you and your agents can run idetea from a terminal.

Prefer a single file on Linux? The AppImage runs as is: chmod +x IDE_TEA-*.AppImage and open it; --install-desktop adds it to the menu. On macOS, idetea --install-desktop creates ~/Applications/IDE TEA.app. Building from source is one command: cargo install --locked --git https://github.com/fabiocmazzo/idetea tea-app.

Free code signing on Windows is provided by SignPath.io, certificate by the SignPath Foundation (Code Signing & Privacy Policy).

Optional extras: git for the git panel, gdb 14+ (or lldb-dap on macOS) for debugging, and the language servers you use (next steps).

2. Open a project

A project is just a folder. From a terminal:

idetea                # the current folder
idetea ~/code/my-app  # another folder
idetea src/main.rs    # current folder, with this file open

The IDE gives the prompt back right away. From the app menu, it reopens your last project. The tabs, the active file and the open panels come back the way you left them.

The layout: the file tree on the left, the editor in the middle, panels on the right (outline, preview, Interfaces) and at the bottom (terminal, search, problems, git). Above the editor, breadcrumbs show the file's path and the symbol where the cursor is. The icon bar on the left edge shows and hides each panel; drag a border to resize it.

3. Find anything: three shortcuts

  1. Ctrl+P opens a file by name. Type parts of the name; main.rs:42 jumps to the line.
  2. Ctrl+Shift+P is the command palette: every command, with its shortcut next to it. If you remember one shortcut, make it this one.
  3. F1 lists every shortcut you have now, plus a short guide.

Search the whole project with Ctrl+Shift+F (as you type, respecting .gitignore, with regex and replace).

4. Language servers

5. Terminal and tasks

  • Ctrl+' or Ctrl+` focuses the terminal. + adds another shell in a tab; exit closes it. The IDE's Ctrl+Shift shortcuts keep working while you type in it.
  • Ctrl+Shift+B runs a task: what the IDE finds in the project (cargo, package.json scripts, Makefile targets) plus your own, from the config: 
    # .idetea/config.toml in the project
[tasks]
"server" = "cargo run -- --port 8080"

6. Git

Ctrl+Shift+G opens the git panel: stage and unstage, colored diff, commit, discard (with confirmation), push, pull and fetch. It uses your installed git, so your config, hooks, ssh agent and credential helper apply. The branch and the number of changes are on the status bar.

7. Settings

Ctrl+, opens the settings screen: appearance, extensions, shortcuts (press the keys you want) and language servers. Everything is also in plain TOML:

  • ~/.config/idetea/config.toml for you;
  • .idetea/config.toml in a project, for that project (it wins over yours).
[ui]
theme = "dark"          # "light", or an iced theme such as "Nord" or "Dracula"
font_size = 14
language = "auto"       # "en", "pt-BR", "es", "fr", "de", "it", "ja", "zh-CN"

[editor]
wrap = true
format_on_save = false
breadcrumbs = true
font = "JetBrains Mono"  # any installed font, or "monospace"
line_height = 1.45

[keys]
"ctrl+shift+p" = "palette.open"
